def find_step_heights() -> np.ndarray:

Where the goal is to find step function heights that will minimize the upper bound C on the following autocorrelation inequality:

|max_{-1/2 <= t <= 1/2} f*f(t)| >= C * (integral_{-1/4}^{1/4} f(x) dx)^2

for any function f: R -> R. f is not required to be nonnegative here -- it may take both positive and negative values. The returned np array should represent the heights of an equal-width step function on [-1/4, 1/4].

You can use this predefined helper function without redefining it:
```
import numpy as np


def compute_upper_bound(step_heights: np.ndarray) -> float:
    """
    AlphaEvolve's own verification formula for C3, for equal-width steps on [-1/4, 1/4]:
        C_upper_bound = |2 * len(h) * max(convolve(h, h)) / sum(h) ** 2|
    """
    convolution = np.convolve(step_heights, step_heights)
    return abs(2 * len(step_heights) * np.max(convolution) / (np.sum(step_heights) ** 2))
```
